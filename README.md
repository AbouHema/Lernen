# Lernen (HTML-Version)

Statische, responsive Lern-Webseite für Deutsch (Arabisch → Deutsch) auf B1–C1-Niveau mit reinem HTML, CSS und JavaScript.

Highlights:
- 160+ Vokabeln und 90+ Sätze (B1, B2, C1, klarer Lernpfad)
- Audio-Ausgabe (Browser SpeechSynthesis) für die deutsche Aussprache von Vokabeln und Sätzen

## Nutzung

Öffne `index.html` direkt im Browser oder starte einen lokalen Server:

```bash
python3 -m http.server 8000
```

Dann im Browser `http://localhost:8000` öffnen.
