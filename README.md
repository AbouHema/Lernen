# Lernen – Deutsch A1–C1

Eine einfache Web-App zum Deutschlernen für arabische Nutzer.

Die Seite enthält Vokabeln, Sätze und Quizze für die Niveaus A1 bis C1 und hilft beim Üben von Aussprache, Hörverständnis und Wortschatz.

## Features

- Deutsch lernen von **A1 bis C1**
- **Vokabeln mit Übersetzung (Deutsch → Arabisch)**
- **Beispielsätze**
- **Mini-Quiz zum Testen**
- **Audio-Funktion zum Anhören der Wörter 🔊**
- **Mikrofon-Aufnahme zum Üben der Aussprache 🎤**
- **Favoriten speichern ⭐**
- **Fortschritt wird im Browser gespeichert**

## Technologien

- HTML
- CSS
- JavaScript
- Browser Speech & Audio APIs

Keine Serverinstallation nötig – alles läuft direkt im Browser.

## Projekt starten

Repository klonen:

git clone https://github.com/abouhema/Lernen.git

cd Lernen

Dann die Datei index.html im Browser öffnen.
