# Lernen (HTML-Version)

Statische, responsive Lern-Webseite für Deutsch (Arabisch → Deutsch) auf B1-Niveau mit reinem HTML, CSS und JavaScript.

## Nutzung

Öffne `index.html` direkt im Browser oder starte einen lokalen Server:

```bash
python3 -m http.server 8000
```

Dann im Browser `http://localhost:8000` öffnen.
## Features

- Vokabeltraining Deutsch → Arabisch
- Beispielsätze
- Quiz-System
- Fortschrittsanzeige
- Favoriten speichern
- Suche über Wörter und Sätze
